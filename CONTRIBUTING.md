# Working with this repository

## Where to edit

- **Reusable formulas** live in `src/qvdfe/`. The tutorials and examples call them. The retained experiment engine in `src/qvdfe/pipeline/_engine/` preserves the original implementation for numerical traceability; parity tests connect the two. Change either implementation only with an explicit scientific justification and regression checks.
- **Empirical pipeline** lives in `src/qvdfe/pipeline/`. It uses explicit external paths, writes to a separate output directory and must not overwrite its source data or frozen reference results.
- **Tutorials** are generated by `teaching/build_tutorials.py`. Edit the cell sources in that file, then run it to regenerate and execute the notebooks, which are stored with their outputs.
- **Examples**: inputs are in each `config.json` and expected values in `expected/results.json`. After an intended change, rerun the example and copy its `results.json` (without the `provenance` block) to `expected/`.
- **Paper reproduction**: the entries in `reproduce/` regenerate figures and calculations from the frozen data. `python reproduce/run_all.py` compares every output with the frozen files.
- **Frozen data** in `data/frozen/` must not be modified. New calculations write their own folder.
- **Current reporting** lives in `data/reporting/v33/` and `reproduce/current_reporting.py`; it is separate from the original release's frozen reporting. Keep support keys and aggregate metrics traceable.
- **Formula–code map**: after adding a label to the paper, add it to `tools/formula_code_map.json`, then run `python tools/make_formula_code_map.py`. The script fails if any label is unmapped or any row does not resolve.

## Before committing

```bash
pytest
python tools/verify_frozen_inputs.py
python reproduce/run_all.py
python tools/make_formula_code_map.py
python teaching/build_tutorials.py        # if tutorials or src/qvdfe changed
python tools/build_example_notebooks.py   # if examples changed
```

## Adding the original data

Follow `data/original/README.md`. Keep raw files out of `data/frozen/`.

## Windows note

In Git Bash heredocs, `\\` collapses to `\`. Write helper scripts that contain backslashes (LaTeX, regular expressions) to a file with an editor instead of piping them through a heredoc.
