Positive bias means overestimation. Rate and bin-emission WAPE use equal five-minute bins.

Cumulative-path WAPE uses bin-end cumulative values. It is identical for the time and vehicle axes, which display the same cumulative series; it is not a set of independent emission errors.

Episode-total APE compares the final sums. It can be smaller than bin-emission WAPE because positive and negative errors can cancel.
